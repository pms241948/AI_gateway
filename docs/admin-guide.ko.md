# 관리자 가이드

이 가이드는 관리자 대시보드를 사용하여 AI Gateway를 관리하는 방법을 설명합니다.

## 1. 대시보드 개요

**대시보드(Dashboard)**는 시스템 상태에 대한 실시간 개요를 제공합니다:

- **총 요청 수(Total Requests)**: 처리된 API 요청의 총 횟수입니다.
- **활성 모델(Active Models)**: 현재 사용 가능한 모델의 수입니다.
- **평균 지연 시간(Average Latency)**: LLM 요청의 평균 응답 시간입니다.
- **오류율(Error Rate)**: 실패한 요청의 비율입니다.
- **사용량 차트(Usage Chart)**: 일일 요청량을 시각적으로 보여줍니다.
- **모델 상태(Model Health)**: 등록된 각 모델 엔드포인트의 상태 표시기입니다.

## 2. 사용자 관리

**Users** 메뉴에서 시스템 사용자를 관리합니다.

### 2.1 사용자 관리
- **목록**: 등록된 모든 사용자, 역할 및 상태를 확인합니다.
- **편집**: 사용자 역할(관리자/일반 사용자)을 변경하거나 비밀번호 및 이메일을 수정합니다.
- **비활성화**: 계정을 삭제하지 않고 접근을 제한할 수 있습니다.

### 2.2 API 키
- 사용자는 애플리케이션별로 여러 API 키를 생성할 수 있습니다.
- 관리자는 필요한 경우 사용자의 API 키를 조회하거나 취소할 수 있습니다.

## 3. 조직 관리

**Organizations** 메뉴에서 조직을 관리합니다.

### 3.1 설정
- **조직 생성**: 사용자와 모델을 그룹화하기 위한 새 조직을 정의합니다.
- **조직 그룹**: 조직 내에 하위 그룹(예: "개발팀", "마케팅팀")을 생성하여 특정 모델 접근 권한을 할당합니다.

### 3.2 가입 요청 (Join Requests)
**Join Requests** 메뉴에서 멤버십 신청을 처리합니다:
- **상태**: 대기 중(Pending), 승인됨(Approved), 거절됨(Rejected) 요청을 확인합니다.
- **작업**: 요청을 승인하거나 거절합니다.
- **상세보기**: "상세보기" 버튼을 클릭하여 사용자의 가입 요청 사유를 확인합니다.

## 4. 프로바이더 및 모델 관리

### 4.1 프로바이더 (Providers)
**Providers** 메뉴에서 LLM 백엔드를 구성합니다:
- **추가**: OpenAI, Anthropic 같은 외부 서비스나 Ollama/vLLM 같은 로컬 서비스를 등록합니다.
- **유형(Type)**: 지원되는 유형(openai, azure, anthropic, ollama, vllm, mock) 중 하나를 선택합니다.
- **Base URL**: 프로바이더의 API 엔드포인트(예: `http://ollama:11434`)를 입력합니다.
- **인증**: 필요한 경우 API 키를 설정합니다.

### 4.2 모델 (Models)
**Models** 메뉴에서 사용 가능한 모델을 정의합니다:
- **별칭(Alias)**: 클라이언트가 API 호출 시 사용할 모델 이름입니다(예: `gpt-4`).
- **표시 이름(Display Name)**: UI에 표시될 읽기 쉬운 이름입니다.
- **라우팅**: 별칭을 하나 이상의 프로바이더 엔드포인트에 매핑합니다.
- **로드 밸런싱**: 여러 엔드포인트가 할당된 경우 요청이 분산 처리됩니다.

## 5. 로그 및 모니터링

**Request Logs** 메뉴에서 로그를 확인합니다:
- **검색**: Request ID, 모델, 사용자, 상태 코드로 로그를 필터링합니다.
- **상세보기**: 전체 요청 페이로드, 응답 내용, 지연 시간을 확인합니다.
- **내보내기**: 외부 분석을 위해 로그를 CSV로 다운로드합니다.

## 6. 보안 기능

### 6.1 PII 마스킹
활성화된 경우, 시스템은 프롬프트 입력 및 모델 출력에서 민감한 정보(이메일, 전화번호 등)를 자동으로 감지하고 마스킹합니다.

### 6.2 AI 보안 스캔 (Garak)
**Security Scan** 메뉴에서 보안 취약점을 점검합니다:
- **스캔 실행**: 특정 모델에 대해 취약점 스캔을 시작합니다.
- **프로브 유형**: 테스트할 공격 유형(예: 인젝션, 탈옥, 환각)을 선택합니다.
- **보고서**: 각 항목에 대한 상세 성공/실패 결과를 확인합니다.
